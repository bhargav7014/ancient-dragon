# DRACONIS — Cosmic Dragon Lore

An interactive, immersive web experience showcasing ancient dragon lore, interactive 3D/canvas visual effects, constellation lore, and elemental dragon species.

## 🐉 Features

- **Interactive Constellation & Starfield**: Dynamic Canvas-based celestial background with reactive dragon stardust.
- **Lore Chronicles**: Deep lore covering Ancient Dragon taxonomy, mythos, elemental breath forms, and cosmic relics.
- **Scroll-driven Visuals**: Fluid animations, glowing runes, and responsive layout.
- **Audio & Ambient Effects**: Custom sound design and interactive particle effects.

## 🚀 Tech Stack

- **Vite**
- **HTML5 Canvas / Vanilla JS**
- **Modern CSS** (Glassmorphism, CSS Custom Properties, Responsive Layouts)

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
